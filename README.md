# Dino vs Dino!

A cheerful, touch-first browser game for young kids. Two players take turns holding the big button: the carnivore **chomps** and the herbivore **dashes**. Each successful move earns the next score: 7, 8, 16, 24 … up to 72. First dino to 72 wins!

## Dino pairs

- Majungasaurus (carnivore) vs Rapetosaurus (herbivore): Madagascar
- Allosaurus (carnivore) vs Stegosaurus (herbivore): USA

## Play locally

Open `index.html` in any modern browser. It has no build step or dependencies.

## Publish to GitHub

```powershell
git commit -m "Create Dino vs Dino game"
git branch -M main
git remote add origin https://github.com/arnavmallan/dino-vs-dino.git
git push -u origin main
```
